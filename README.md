# Flipkart Page Clone

A responsive **Flipkart-inspired e-commerce webpage** created using **HTML and CSS**.

This project recreates the layout and visual appearance of an older version of the Flipkart homepage as a frontend practice project.

## 🚀 Live Demo

[View the Website](https://itspavan06.github.io/FilpkartPage/)

## 📌 Features

- Flipkart-inspired navigation bar
- Search bar UI
- Login section
- Shopping cart section
- Become a Seller section
- Product category navigation panel
- Hero banner section
- Product offer sections
- Smartphone deals section
- Product cards with images and pricing
- Promotional banner sections
- Gadgets and appliances section
- Responsive layout for different screen sizes
- Responsive footer
- Hover effects on product and category images

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📱 Responsive Design

The webpage is designed to adapt to different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile
- Small mobile devices

CSS media queries are used to adjust the layout, sizing, spacing, and positioning of elements according to the screen width.
